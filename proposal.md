\# Texture Resolution Calculator



\## Repository

https://github.com/smaxey34/Maxey\_Seth\_PFDA\_Final.git



\## Description

Calculates the optimal texture resolution of 3d assets for animation or games



\## Features

* Feature 1

  * Calculates texture resolution based on object size and distance from camera/player

    * takes input, calculates a value and then pulls a resolution from a library
* Feature 2

  * Gives unique output pertaining to either games or animation

    * Outputs either a game ready or animation ready output based on given input
* Feature 3

  * Convert given texture to optimal resolution

    * Uses the pillow extension to convert a given image into the correct resolution



\## Challenges

* Learn optimal conditions for texture resolutions in order to meet industry performance needs
* Learn to streamline image input and output



\## Outcomes

Ideal Outcome:

* The user will be able to input the type of media, object height and distance from camera/player and the program will out put the optimal texture resolution as well as convert a given image to the correct size



Minimal Outcome:

* The program uses at least one variable to output an optimal image size
